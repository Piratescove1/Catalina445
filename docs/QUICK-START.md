# Catalina 445 App — Quick Start (do this at the dock)

> ⚓ **Set up every device while you still have wifi or cell signal.** Once you
> lose connectivity offshore, the app keeps working — but you can't create an
> account or add a *new* device without signal.

## 1. Open the app
Go to the app link in Safari (or your browser). Tip: tap Share → **Add to Home
Screen** so it opens like a real app.

## 2. Create your account
- Tap **Create account**, choose a **username** and **password** (6+ characters).
- ✍️ **WRITE DOWN THE RECOVERY CODE it shows you.** Keep it somewhere safe that
  is NOT just on the phone (a note in your ditch bag, a password manager, etc.).
  **This is the only way back in if you forget your password.**
- Your existing boat data loads automatically.

## 3. Turn on Face ID (optional but handy)
- Tap the **⚙️ gear → Face ID / fingerprint unlock → Turn on**, and approve the
  prompt. Next time you can unlock with a glance instead of typing.

## 4. Set up any other devices (before you leave!)
- On each phone/tablet, open the app and log in. All devices on the same boat
  share the same data.

## 5. Make a backup
- **⚙️ gear → Download Full Backup (JSON)** and save the file somewhere safe
  (email it to yourself, save to Files). Do this before big trips.

---

### Everyday use
- **Ship's Stores / Provisions** — track what's aboard and build shopping lists.
- **Voyage Log** — start a voyage, log position/conditions (GPS button fills
  lat/long; you can also type them and edit the date/time).
- **Maintenance** — record work done and plan future projects.
- **Ditch Bag** — your abandon-ship checklist.

### If you forget your password
Tap **Forgot password?** on the login screen, enter your username and your
**recovery code**, then set a new password.

### It works offline
Everything runs with no signal. Changes sync to your other devices and the cloud
automatically the next time you have connectivity.
